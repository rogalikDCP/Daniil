# SMM-пакет для @chester_perekup (Илья Честер, честный перекуп, Рыбинск)

Подготовлено 11–21 сентября 2026. Всё в одной папке.

## Начните отсюда
- **`CHESTER_SMM_FULL.md`** — сводный документ: весь анализ, тренды, 48 сценариев, сторителлинг, контент-план, 80 хуков, источники и описание использованных скиллов в одном файле.

## Скиллы (`skills/`)
| Папка | Назначение |
|---|---|
| `skills/chester-smm/` | Проектный скилл: инварианты проекта (герой, TOV, рубрикатор, правила хуков и CTA, юр. контур) и маршрутизация по файлам. Копия подключена в `.claude/skills/chester-smm/` этого репозитория, так что Claude Code подхватывает его автоматически |
| `skills/smm-expert/` | Методика SMM: стратегия → рубрикатор → контент-план, ограничения для РФ 2026 |
| `skills/social/` | Хуки, структура короткого видео, реверс-инжиниринг вирусного контента, лимиты платформ |
| `skills/video/` | Продакшн, монтаж, нарезка длинных видео, ИИ-инструменты |

Чтобы использовать скиллы в другом репозитории, скопируйте нужные папки из `skills/` в `.claude/skills/` того репозитория.

Главное ограничение: Instagram недоступен из среды подготовки, поэтому ролики июля–сентября 2026 не просмотрены. Таблица аудита в файле 01 закрывает этот пробел за 40 минут работы в Insights.
